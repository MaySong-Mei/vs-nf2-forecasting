# Frank 项目  前庭神经鞘瘤纵向预测

文档整理：2026-09-11。以下 proposal 依据已核查的 Sep 4 会议记录及 Sep 8–9 项目更新；待确认状态不等于今天仍未完成，需要新证据更新。

## 项目内容

研究稀疏、不规则随访中的前庭神经鞘瘤（VS）未来生长预测。首先建立可信的体积／增长率预测基线，检验常规 MRI 是否在既往体积和增长轨迹之外提供增量信息；进一步检验散发性 VS 的纵向知识能否帮助 NF2 相关 VS，以及何时发生负迁移。

当前 proposal 有两条主要方向：

1. **信息与模型假设的分步比较**：线性／线性混合效应模型开始，分别比较增加强度、几何、radiomics、学习表示的收益。固定模型比较输入，再固定输入比较模型，避免同时改变信息和容量。
2. **散发性 → NF2 迁移和样本效率**：比较 NF2-only、公共散发性预训练后适配、合并训练及简单共享参数模型。区分静态影像／分割表示迁移与纵向生长规律迁移，并允许负结果。

长期目标可以扩展到未来形状、局部表面位移和听力风险；完整未来 MRI 生成不是近期承诺。Sep 4 后 Monte Carlo／随机几何已从主线降级为可选后续比较。肿瘤／脑桥强度比候选来自 Manwi；Frank 提出更广泛的纵向与空间生长研究方向。

## 输入与输出

| 项目 | 当前定义 |
|---|---|
| 预测时可用输入 | 当前及此前的体积、时间间隔、疾病类型和可用临床变量；后续加入常规影像、mask、历史形状与归一化强度 |
| 近期输出 | 下一有效随访的体积／体积变化，或经临床确认的增长率目标；模型显式处理预测间隔 |
| 待冻结 | 先做初诊预测还是随访动态预测、具体目标单位、时间范围、协变量及治疗处理规则 |
| 研究单位 | 按患者划分训练与评估；NF2 双侧肿瘤与重复时点留在同一患者分组 |
| 比较原则 | 所有模型使用相同患者、可用历史及调参预算；不使用未来信息构建输入 |

## 价值与成功条件

贡献重点是时间正确、患者独立、可复现的预测增量，以及跨来源／跨疾病迁移的收益与失败范围。架构复杂度、总候选人数和全肿瘤 Dice 提升本身不足以证明临床价值。报告效应大小、患者级不确定性、预测跨度与大小分层，并结合测量噪声解释。
